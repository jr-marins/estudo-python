# 🚀 Backend Flask com Banco de Dados

Projeto desenvolvido como parte dos meus estudos em desenvolvimento backend com Python, utilizando Flask e integração com banco de dados.

Este repositório tem como objetivo consolidar conceitos fundamentais de backend, criação de rotas, persistência de dados e estruturação de aplicações reais.

---

## 🧠 Sobre o projeto

Aplicação backend construída com Flask que realiza operações básicas em banco de dados (CRUD).

Este projeto foi criado com foco em aprendizado prático, abordando:

- Estruturação de aplicações backend
- Criação de rotas HTTP
- Integração com banco de dados
- Organização inicial de projeto
- Separação entre lógica e interface
- Evolução da lógica de programação

Marca meu primeiro contato prático com Flask conectado a banco de dados.

---

## 🛠️ Tecnologias utilizadas

- Python  
- Flask  
- SQLite  
- HTML / CSS (básico)
